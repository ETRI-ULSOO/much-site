## 조합형 데이터셋

협약 목표 4,500건을 크게 넘어 12,131건을 만들었습니다. 데이터는 네 갈래로 구성됩니다.

### 3D 형상 데이터

유물의 입체 형태를 담은 데이터입니다. 웹에서 바로 열 수 있도록 glTF 형식으로 만든 뒤 Nexus 형식으로 다시 압축했습니다.

### RTI 데이터

여러 방향에서 조명을 바꿔 가며 촬영해 표면의 미세한 요철까지 담는 방식입니다. 비면의 글자나 금속 표면의 흔적처럼 형태보다 질감이 중요한 대상에 씁니다.

### 기가픽셀 이미지

한 장의 사진 안에 수억 화소를 담아, 화면에서 계속 확대해도 세부가 무너지지 않는 이미지입니다.

### 메타데이터

유물의 이름과 시대, 재질, 출토지, 소장 정보를 표준 항목에 맞추어 정리한 자료입니다.

1차년도에는 유물 56점과 부재 66점을 대상으로 애셋 최적화를 진행했고, 3D 60건, RTI 15건, 기가픽셀 5건으로 나뉩니다.

### 학습·검증용 데이터셋 확대 구축 77,976건

조합형 데이터셋과는 별개로, 인공지능 모델을 학습시키고 검증하기 위한 데이터를 77,976건 모았습니다 (최종보고서 64쪽, 3단계 실적). 구성은 다음과 같습니다.

| 갈래 | 건수 |
| --- | --- |
| 전시 유물 카드 문자 인식(OCR) | 1,272건 |
| 문화 공공데이터 광장 오픈 API | 2,065건 |
| 국립중앙박물관 누리집 유물 | 4,173건 |
| 전시 정보 | 626건 |
| 시험 검증용 | 69,840건 |

이 데이터를 반영한 결과 의미 기반 검색의 정확도가 62.58%에서 68.83%로 6.25%포인트 올랐습니다. 문화유산 분류·태깅 및 관계정의서는 3.0판까지 확장해 인스턴스 1,714건과 아이템 5,926건을 담았습니다.

## 성능 지표

플랫폼에 들어간 인공지능 기술의 성능을 협약에서 정한 비교 수준과 대조했습니다. 여덟 항목 모두 비교 수준을 넘었습니다 (최종보고서 69쪽).

| 지표 | 뜻 | 실적 |
| --- | --- | --- |
| IS (Inception Score) | 생성한 이미지가 얼마나 또렷하고 다양한가 | 3.52 |
| FID (Fréchet Inception Distance) | 생성한 이미지가 실제 사진과 얼마나 가까운가, 낮을수록 좋음 | 23.3 |
| MS-SSIM | 복원한 이미지가 원본과 얼마나 닮았는가 | 0.878 |
| mAP | 유물 검출의 평균 정확도 | 68.61 |
| 인식률 | 유물 분류가 맞은 비율 | 92.43% |
