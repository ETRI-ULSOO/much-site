## 1차년도 (2023년) — 데이터 구조를 세웠습니다

### W3C 시맨틱웹 표준 구성 설계

문화유산 데이터를 국제 표준 방식으로 담기 위해 W3C가 정한 시맨틱웹 규격에 맞추어 데이터 구조를 설계했습니다. 시맨틱웹은 기계가 자료의 뜻을 따라갈 수 있게 만드는 웹 기술입니다.

### 변환 및 관리 데이터베이스 구성 설계

기관마다 다른 형식으로 들어오는 자료를 표준 구조로 바꾸고, 그렇게 바뀐 자료를 보관하고 꺼내 쓰는 데이터베이스를 설계했습니다.

### 데이터 유형 분류

문화유산 디지털 데이터를 3D 형상, RTI(여러 방향에서 조명을 바꿔 가며 찍어 표면 질감을 담는 방식), 기가픽셀 이미지, 메타데이터 네 갈래로 나누었습니다.

### 메타데이터 설계

유물마다 어떤 항목을 반드시 기록해야 하는지 정했습니다.

### 계층구조 기반 관계 가시화

유물이 속한 분류 체계를 나무 구조로 펼쳐 보이는 방식을 만들었습니다.

### 가시화 서비스

관계를 찾아 들어가는 길을 세 가지로 마련했습니다. 키워드로 찾기, 카탈로그를 넘겨 보기, 그리고 SPARQL 질의문으로 직접 묻기입니다. SPARQL은 지식그래프에 질문을 던지는 표준 질의 언어입니다.

### 아카이브 기반 가시화

이미 쌓여 있는 소장 자료를 그대로 불러와 관계망으로 보여 주는 방식을 만들었습니다.

### CNN 이미지 변환

합성곱 신경망(CNN)을 써서 유물 이미지를 다른 형태로 바꾸는 기술을 시험했습니다.

### 문화유산 애셋 데이터 최적화

{/* 구 사이트에서는 이 제목이 "문화유산 애셋 데이터 최적"에서 끊겨 있었습니다. */}

고해상도 3D 데이터를 웹에서 바로 열 수 있는 크기로 줄이는 작업입니다. glTF 형식으로 만든 자료를 Nexus 형식으로 다시 압축해, 화질을 크게 잃지 않으면서 불러오는 시간을 줄였습니다. 1차년도에 유물 56점, 부재 66점을 처리했고 3D 60건, RTI 15건, 기가픽셀 5건으로 나뉩니다.

{/* 구 사이트의 "gITF"는 glTF(GL Transmission Format)의 오기입니다. */}

## 2차년도 (2024년) — 인공지능 기능을 얹었습니다

### 인공지능 모델 기반 연관성 분석과 추천

유물 사이의 연관성을 모델이 판단해 관련 유물을 추천하는 기능입니다.

### 이미지 분류

유물 사진을 종류별로 자동 분류합니다.

### 지능형 문화유산 플랫폼

앞서 만든 데이터 구조와 인공지능 기능을 하나의 플랫폼으로 묶기 시작했습니다.

### 지식그래프 데이터 탐색

그래프를 따라가며 원하는 유물에 이르는 탐색 화면을 만들었습니다.

### 문화유산 기반 인공지능 활용 결과물

인공지능으로 만들어 낸 이미지와 복원 결과를 정리했습니다.

## 3차년도 (2025년) — 플랫폼으로 묶고 실증했습니다

### MUCH 플랫폼

앞의 결과를 하나의 플랫폼으로 완성했습니다.

### 인공지능 연구 결과의 기능 구현

연구로 검증한 모델을 플랫폼 안에서 실제로 쓰이는 기능으로 만들었습니다.

### 3D 가우시안 스플래팅

여러 장의 사진에서 3차원 장면을 만들어 내는 최신 방식입니다. 점이 아니라 작은 타원 덩어리를 쌓아 표현하기 때문에, 기존 방식보다 실제에 가까운 모습을 빠르게 보여 줍니다.

### 지능형 관계 기반 시각화

유물 사이의 관계를 따라가며 볼 수 있는 화면을 완성했습니다.

### MUCH 지식그래프

유물과 시대, 재질, 기법의 관계를 담은 지식그래프를 구축했습니다.

### 인공지능 기반 동선 안내

관람객의 관심사에 맞추어 전시장 안에서 어느 순서로 볼지 안내하는 기능입니다.

### 반가사유상 시범 콘텐츠

국보 반가사유상을 대상으로 삼아 플랫폼의 기능을 처음부터 끝까지 이어 보였습니다.
