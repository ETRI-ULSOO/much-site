## Research Sequence

The work was divided into stages across three years. In the first year, the project decided what structure would hold the data; in the second year, it added AI features on top of that structure; and in the third year, it brought everything together into a platform and verified it at an actual museum.

{/* 대체 텍스트: 2023년 데이터 구조 설계, 2024년 인공지능 기능 구현, 2025년 플랫폼 통합과 실증으로 이어지는 세 단계 로드맵입니다. */}

## Year 1 (2023) — Building the Data Structure

### W3C Semantic Web Standard Configuration Design

To hold cultural heritage data in an internationally standardized way, the data structure was designed to conform to the Semantic Web specification set by the W3C. The Semantic Web is a web technology that lets machines follow the meaning of data.

### Conversion and Management Database Configuration Design

A database was designed to convert material arriving in different formats from each institution into a standard structure, and to store and retrieve the converted material.

### Data Type Classification

Digital cultural heritage data was divided into four types: 3D shapes, RTI (reflectance transformation imaging, which captures surface texture by shooting under changing light directions), gigapixel images, and metadata.

### Metadata Design

The project defined which fields must be recorded for every artifact.

### Hierarchy-Based Relationship Visualization

A method was built to display the classification system an artifact belongs to as an expandable tree structure.

### Visualization Service

Three ways of finding relationships were provided: searching by keyword, paging through a catalog, and querying directly with SPARQL. SPARQL is a standard query language for asking questions of a knowledge graph.

### Archive-Based Visualization

A method was built to load existing collection material as it is and display it as a relationship network.

### CNN Image Conversion

A technique for converting artifact images into other forms using a convolutional neural network (CNN) was tested.

### Optimizing Cultural Heritage Asset Data

{/* 구 사이트에서는 이 제목이 "문화유산 애셋 데이터 최적"에서 끊겨 있었습니다. */}

This work reduced high-resolution 3D data to a size that can be opened directly on the web. Material created in glTF format was recompressed into Nexus format, cutting load time without significant loss of image quality. In Year 1, 56 artifacts and 66 components were processed, divided into 60 items of 3D data, 15 of RTI, and 5 of gigapixel images.

{/* 구 사이트의 "gITF"는 glTF(GL Transmission Format)의 오기입니다. */}

## Year 2 (2024) — Adding AI Features

### AI Model-Based Relevance Analysis and Recommendation

A feature in which a model judges the relevance between artifacts and recommends related ones.

### Image Classification

Artifact photographs are automatically classified by type.

### Intelligent Cultural Heritage Platform

Work began on combining the data structure and AI features built so far into a single platform.

### Knowledge Graph Data Exploration

An exploration screen was built that follows the graph to reach a desired artifact.

### Results of AI Applications Based on Cultural Heritage

Images generated by AI and restoration results were compiled.

## Year 3 (2025) — Integrating the Platform and Demonstrating It

### MUCH Platform

The preceding results were completed as a single platform.

### Implementing AI Research Results as Features

Models validated through research were turned into features actually used within the platform.

### 3D Gaussian Splatting

A recent method for generating a 3D scene from multiple photographs. Because it represents the scene with small ellipsoid blobs rather than points, it renders a more realistic view faster than earlier methods.

### Intelligent Relationship-Based Visualization

A screen that lets users follow relationships between artifacts was completed.

### MUCH Knowledge Graph

A knowledge graph capturing the relationships among artifacts, periods, materials, and techniques was built.

### AI-Based Route Guidance

A feature that guides visitors on which order to view exhibits in, based on their interests.

### Pensive Bodhisattva Pilot Content

Using the National Treasure Pensive Bodhisattva as the subject, the platform's features were demonstrated end to end.
